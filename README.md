One dad joke, told out loud at the barbecue:

> My kids asked why I talk to the grill. I told them it's the only one that appreciates my rare opinions — they're always well done.

A double steak pun — *rare* opinions, *well done* — landing in the last three words, with Dad as the only one the grill listens to.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the joke to `/output/entry.txt` (130 characters, deterministic, Node 22 standard library only, no network).
